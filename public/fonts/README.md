# Font Files for آیریک

Place your font files here in `.woff2` format.

## Current Font: Vazirmatn

Place the following files in this directory:

1. `Vazirmatn-Regular.woff2` — weight 400
2. `Vazirmatn-Medium.woff2` — weight 500
3. `Vazirmatn-Bold.woff2` — weight 700

## How to Change the Font

1. Place your new font files in this directory.
2. Update the `@font-face` declarations in `app/globals.css`.
3. Update the `--font-family` variable in `app/globals.css`.
4. That's it — the entire site will use the new font.

## Where to Get Vazirmatn

Download from: https://github.com/rastikerdar/vazirmatn/releases
